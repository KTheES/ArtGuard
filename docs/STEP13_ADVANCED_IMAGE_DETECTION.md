# STEP 13 고급 이미지 탐지

상품 사진 속에 작게 배치된 작품을 찾기 위해 전체 이미지 임베딩과 영역 임베딩을 함께 비교합니다.

## 처리 방식

- AI 서비스의 `POST /v1/region-embeddings`가 전체 이미지와 65% 크기의 겹침 영역 5개를 한 배치로 처리합니다.
- 영역 규격은 `fixed-overlap-5-v1`이며 중앙, 좌상, 우상, 좌하, 우하 좌표를 0~1 값으로 저장합니다.
- `product_image_region_embedding`은 전체 벡터를 부모로 참조합니다. 현재 활성 상품·현재 이미지 해시에 속한 벡터만 검색합니다.
- 탐지는 전체와 영역 후보를 합친 뒤 상품별 최고 cosine 유사도 하나만 결과로 남깁니다.
- 영역 저장과 같은 트랜잭션에서 새 상품 탐지 신호를 만들어 기존 탐지 결과도 영역 기준으로 다시 계산합니다.
- 결과 상세의 `matchedRegion`이 `null`이면 전체 이미지, 값이 있으면 실제 매칭 영역과 좌표를 뜻합니다.

Flyway V11은 기존 완료 상품 임베딩 작업을 한 번 다시 큐에 넣습니다. 배포 시 AI·S3가 준비되지 않았다면 `EMBEDDING_ENABLED=false`로 migration만 적용하고, 준비 후 작업자를 켜세요.

## 검증 결과

- AI 단위 테스트: 39개 통과, 모델 테스트 3개는 기본 실행에서 제외
- STEP 13 실제 CPU 모델 평가: 1개 통과
  - 합성 티셔츠: 전체 0.7974, 최고 영역 0.8790, +0.0816
  - 합성 머그: 전체 0.6931, 최고 영역 0.8694, +0.1764
- 백엔드 단위 테스트와 `bootJar`: 통과
- PostgreSQL/pgvector migration 통합 실행: Docker 엔진이 없어 미실행

합성 평가는 기능 회귀 기준입니다. 실제 AliExpress 상품의 정밀도·재현율이나 저작권 침해 여부를 의미하지 않습니다.

## 운영상 제한

고정 영역 방식은 회전, 원근 왜곡, 아주 작은 삽입물, 영역 경계를 가로지르는 작품에 약할 수 있습니다. STEP 14에서 pHash/dHash를 추가하고 이후 실제 검증 데이터로 영역 크기와 임계값을 조정합니다.
