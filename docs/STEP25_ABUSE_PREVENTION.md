# STEP 25 부정 사용 방지 — 1차 구현

업로드 URL 발급을 계정 생성 후 7일 미만은 최근 24시간 5회, 이후는 50회로 제한합니다. 구독의 보유 작품 수 제한과 별도로 적용됩니다. 한도 도달은 HTTP 429 / UPLOAD_DAILY_LIMIT입니다. 사용하지 않은 티켓도 포함하며 작품 삭제로 한도가 초기화되지 않습니다. 실패해 트랜잭션이 롤백된 발급 요청은 포함되지 않습니다.

DB의 활성 사용자 행을 잠그고 티켓 수를 검사한 뒤 동일 트랜잭션에서 발급 티켓을 저장합니다. 여러 서버에서도 같은 사용자에 대한 발급은 직렬화됩니다. DB 시각으로 계정 나이와 24시간 구간을 계산합니다. V20은 기존 10분 만료 시각에서 티켓 생성 시각을 역산합니다. 향후 티켓 정리 작업은 최소 최근 24시간 기록을 유지해야 합니다.

작품 등록 시 업로드된 원본 바이트의 SHA-256, 크기, 검증된 콘텐츠 유형 및 가로·세로 크기를 artwork_source_metadata에 저장합니다. 이미지 정규화 이전 바이트의 해시입니다. 기존 작품의 원본 해시를 추정해 채우지 않습니다. 메타데이터 수정·삭제는 DB 트리거로 차단하며, 작품 등록 재시도는 중복 기록을 만들지 않습니다. EXIF·GPS 등 추가 개인정보는 추출하지 않습니다.

이 정보는 파일을 식별하는 보조 기록이며 저작권 소유 증명이 아닙니다. 원본 파일 자체는 기존 이미지 정규화 정책대로 저장되므로 원본 파일 전체 보관 기능을 의미하지 않습니다. 기존 이미지 크기 제한, 구독 용량 제한, 신고 시 권한 확인은 유지합니다.

## 검증

단위 테스트는 계정 나이 경계, 원본 SHA-256, 한도 초과 시 저장소 호출 차단, 작품 등록 시 메타데이터 기록을 검증합니다. PostgreSQL 통합 테스트는 티켓 집계·사용자 분리·만료 범위·비활성 사용자 차단을 포함합니다. Docker 부재로 통합 테스트와 V20 실제 적용 검증은 미완료이며 동시 요청 부하 검증도 남아 있습니다.
