# Architecture Decision Records

중요한 기술 선택의 배경과 결과를 변경 이력과 함께 보존합니다.

## 작성 규칙

1. `TEMPLATE.md`를 복사해 `NNNN-short-title.md`로 작성합니다.
2. 번호는 기존 문서의 다음 순번을 사용합니다.
3. 상태는 `제안됨`, `승인됨`, `대체됨`, `폐기됨` 중 하나입니다.
4. 결정 변경 시 기존 문서를 지우지 않고 새 ADR에서 대체 관계를 연결합니다.
5. API, 트러블슈팅, 회의 액션, FAQ에 영향이 있으면 관련 문서도 함께 연결합니다.
