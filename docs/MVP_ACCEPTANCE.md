# 로컬 MVP 수용 점검표

작성일: 2026-09-15, 2026-09-29 갱신. 전체 상태: **PASS (M01~M12 PASS)**. 격리된 로컬 환경의 상세 실행 증거는 [STEP 33 수용 시험 결과](STEP33_MVP_ACCEPTANCE_RESULT.md)에 기록했습니다.

## 준비

격리된 테스트 DB·버킷·계정과 사용 권한을 확보한 artwork.png, 해당 작품을 포함한 shirt.png, 무관한 음성 상품을 사용합니다. fixture 출처·해시를 기록합니다. 운영 DB나 실제 수신자에게 테스트 데이터를 보내지 않습니다. 메일은 로컬 수신함으로 검증합니다.

[프로젝트 실행 안내](../README.md)와 [상품 임베딩 안내](STEP7_PRODUCT_EMBEDDING.md)에 따라 저장소·AI·임베딩·탐지·Mock 수집을 설정합니다. 비밀값은 실행 환경에 두고 결과 보고서에서는 제외합니다. 플랜 한도와 이메일 권한, 알림 심각도 조건을 확인합니다. 비교 상품의 점수를 인위적으로 수정해 통과시키지 않습니다.
