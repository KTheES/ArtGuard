# STEP 32 입력 경계값 테스트 확장

검증일: 2026-09-29. **신규 단위 테스트 105개 추가 및 전체 백엔드 검증 통과**.

## 목적

기존 서비스·컨트롤러 중심 테스트를 보완하기 위해 외부 요청 DTO의 허용 경계와 거부 조건을 각각 독립된 JUnit 매개변수 테스트로 고정했다. 단순 반복 데이터가 아니라 인증, 파일 크기·형식, 문자열 길이, 페이지 범위, 낙관적 잠금 버전 및 권리 확인처럼 API 계약과 보안에 직접 영향을 주는 입력을 대상으로 한다.

## 남은 범위

이번 확장은 서버 입력 계약의 자동 회귀 검증이다. 브라우저에서 실제 서비스를 연결하는 [MVP 수용 시험](MVP_ACCEPTANCE.md) M01~M11, 실제 AliExpress 호출, 운영 SMTP·S3·Stripe, 실제 데이터 정확도·부하·보안 검증을 대신하지 않는다.
