# ArtworkGuard Wiki

ArtworkGuard는 등록한 창작물과 온라인 상품 이미지의 유사 후보를 탐지하고, 사용자가 검토할 수 있는 증거를 정리하는 프로젝트입니다. 탐지 결과는 법적 판정이 아닌 검토 후보입니다.
