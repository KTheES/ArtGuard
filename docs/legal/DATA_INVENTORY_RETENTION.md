## 외부 처리 흐름

- S3 호환 저장소: 업로드·작품·증거·원본 자료. AWS_REGION 기본 us-east-1은 실제 배포 국가를 증명하지 않습니다. S3_ENDPOINT에 따라 다른 공급자가 될 수 있습니다.
- AI 서비스: 백엔드가 서명 이미지 URL을 구성된 AI 서비스에 전달하고 AI가 이미지를 읽습니다. 기본 루프백 설정과 실제 운영 위치는 별개입니다. 현재 서비스 경로는 추론용이며 별도 학습 재이용 코드는 확인되지 않았습니다. 제3자 업체 정책까지 학습 미사용을 보장하지 않습니다.
- SMTP: 이메일 인증 코드 또는 탐지 알림 내용을 메일 공급자가 처리합니다. 발송 시스템의 로그·보관기간을 확인해야 합니다.
- Stripe: 활성화된 Checkout 코드는 이메일·사용자 UUID·플랜 식별 정보를 전달합니다. 카드 입력은 외부 Checkout 경로이며 이 저장 목록에 카드 원문 컬럼은 없습니다. 공급자의 실제 수집·보관은 계약 문서로 확인합니다.
- AliExpress API·상품 이미지 원본 호스트: 계정 권한·상품 요청·이미지 다운로드 경로 검토가 필요합니다. 사용자 이미지가 해당 검색 API로 전송된다고 단정하지 않습니다.
