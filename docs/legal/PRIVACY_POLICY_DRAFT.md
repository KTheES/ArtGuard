# ArtworkGuard 개인정보 처리방침 초안

**내부 검토용·미시행. [미정: ...] 항목을 확정하고 실제 삭제·권리 행사 기능과 일치시키기 전에는 공개하지 않습니다.**

운영자: [미정: 법인/개인사업자 명칭·주소]. 개인정보 보호책임자/문의 창구: [미정: 담당자·부서·연락처]. 시행일·버전: [미정].

## 1. 처리 목적과 항목

계정 제공과 보호를 위해 이메일, 닉네임, 비밀번호 해시, 사용자 ID, 계정 상태와 가입·인증 기록을 처리합니다. 작품 등록·유사 이미지 탐지를 위해 작품 이미지, 제목·설명, 파생 이미지·특징값, 상품·판매자 정보, 탐지·증거 기록을 처리합니다. 결제를 선택하면 외부 결제 서비스의 고객·구독·거래 연결 정보를, 알림을 사용하면 수신 이메일과 발송 내용을 처리합니다.

소유권 자료·프로필 확인·원본 파일 첨부는 선택 기능입니다. 제출한 URL·설명·파일 내부의 개인정보와 검토 결과를 처리할 수 있으므로 필요한 자료만 제출해야 합니다. 작품 업로드와 선택적 원본 파일 첨부의 용도를 구분합니다. 필수 처리의 항목별 법적 근거 및 선택 기능의 동의 여부는 [미정: 처리 근거 표]에서 확정합니다. 처리방침 고지를 모든 처리의 동의로 취급하지 않습니다.

## 2. 수집 방법과 보유기간

사용자 입력·파일 업로드·서비스 이용에 따른 생성 기록·허용된 외부 상품 API·결제 및 메일 연동을 통해 처리합니다. 각각의 항목, 법적/업무 근거, 목적 종료 기준과 파기 기간은 [미정: 항목별 보유기간 표]입니다. 다른 법령에 따라 보존할 항목이 있다면 실제 적용 법령·항목·기간·분리 보관 방식을 명시합니다.

현재 기술상 작품 삭제는 목록 숨김과 모니터링 중지이며 파일·증거·백업 전체의 파기를 뜻하지 않습니다. 인증 코드나 프로필 확인의 사용 만료도 데이터 파기와 다릅니다. 이 차이는 실제 파기 절차 구현 뒤 정확한 운영 설명으로 확정해야 합니다.

## 3. 제공·위탁·국외 이전

[미정: 수탁업체·제공받는 자·국가·항목·목적·기간·근거·이전 방식·문의/거부 방법]. 현재 연결 가능한 S3 호환 저장소, AI 서버, SMTP, Stripe에 대해 실제 계약과 배포 위치를 확인한 표를 포함합니다. 공급자 전체가 이미 운영 중이라고 표시하지 않습니다. 사용자가 외부 마켓에 직접 제출하는 신고는 해당 마켓에서 별도 처리됩니다.

## 4. 권리 행사와 파기

이용자는 적용 법령에 따른 열람·정정·삭제·처리정지 등의 요청을 [미정: 실제 접수 채널]로 할 수 있습니다. 본인 또는 적법한 대리인 확인에 필요한 최소 자료만 요청하고, 처리 결과·제한 사유·이의 방법을 안내하는 절차를 마련합니다. 자동 삭제 완료를 현재 제공 기능처럼 고지하지 않습니다.

확정할 파기 범위에는 DB 원본·파생 데이터, 객체 버전, 캐시·큐, 임시 파일과 백업을 포함합니다. 증거·감사 보존이 필요하다는 이유만으로 모든 정보를 무기한 보존하는 정책을 채택하지 않습니다. 보존 제한 사유와 재검토 시점을 개별적으로 정합니다.

## 5. 보호조치·추가 처리

현재 코드에는 비밀번호 해시, 인증·역할 확인, 짧은 서명 URL, 파일 해시 검사, 주요 행위 기록이 있습니다. 운영 TLS·암호화·접근 권한·백업·삭제 검증의 실제 적용 결과를 확인한 뒤 보호조치 문구를 확정합니다. 소스 구현만으로 운영 안전성을 보증하지 않습니다.

아동 이용 여부·법정대리인 절차, 쿠키/분석 도구, 인프라 접속정보, 별도 AI 학습 목적은 [미정: 실제 처리 여부와 근거]. 현재 백엔드의 인증은 Authorization 헤더 방식이나, 향후 프런트엔드·제3자 도구가 사용하는 저장 기술은 별도로 조사해야 합니다.

## 6. 변경과 구제

변경 시 공지 방법과 시행일은 [미정]입니다. 요청 창구와 관련 권리 구제 기관 정보를 실제 관할에 맞춰 확인해 제공합니다. 이 초안은 [개인정보 보호법 제30조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033214957)의 공개 항목을 검토하기 위한 문서이며 적법성 검토를 완료한 방침은 아닙니다.
