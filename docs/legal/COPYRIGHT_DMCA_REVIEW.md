# 저작권 신고와 DMCA 대응 검토

**내부 검토 초안·정책 미시행. 실제 신고 전송이나 대리인 등록을 수행하지 않았습니다.**

## 외부 마켓 신고 지원

현재는 탐지 확인 → 초안/증거 선택 → 사용자가 마켓에 직접 신고 → 접수번호·결과 수동 기록입니다. 유사도·원본 파일 해시·프로필 확인만으로 침해를 확정하지 않습니다. 신고자의 권한, 원본·대상 특정, 허락 여부와 적용 예외를 확인하는 검토 항목을 마련합니다. 자동 신고·법률 대리·성공 보장은 제공하지 않습니다.

AliExpress 링크는 [Alibaba IPP 정책](https://ipp.alibabagroup.com/policy/en.htm)을 참고한 신고 경로이며, 지역별 운영 주체와 해당 마켓의 최신 요구사항을 실제 신고 전에 확인합니다. 이 정책은 상품 수집·이미지 복제 허가를 대신하지 않습니다.

## ArtworkGuard 내부 자료에 대한 신고

자체 서비스가 보관하는 작품·원본 파일이 타인의 권리를 침해한다는 신고는 외부 마켓 신고 지원과 별도입니다. 현재 전용 접수·이의제기 API와 운영 창구는 없습니다. 출시 전에 [미정: 담당자·접수 URL/연락처]를 확정하고 사건 번호, 접수 시각, 대상 식별, 제출 권한, 보완 요청, 판단·통지·이의·종결 기록을 관리해야 합니다.

미국법상 Section 512 적용 및 책임 제한 요건은 실제 서비스 유형·관할을 기준으로 검토해야 합니다. 요건 충족이나 안전항 적용을 선언하지 않습니다. [미국 저작권청 안내](https://www.copyright.gov/512/)를 기준으로 신고에는 서명·작품과 대상 위치·연락 정보·적법한 권한 및 정확성에 관한 진술 등 필요한 항목을 확인하고, 이의 통지·복원 여부·소송 통지에 따른 처리 기한을 법률 담당자가 정하도록 합니다. 법정 기한을 임의의 제품 SLA로 대체하지 않습니다.

해당하는 경우 지정 대리인의 공개와 등록 절차가 필요할 수 있으므로 [저작권청 지정 대리인 안내](https://www.copyright.gov/dmca-directory/)에 따라 적용 여부·등록·갱신·공개 정보를 확인합니다. 현재 등록했다고 표시하지 않습니다. 허위·반복 신고와 반복 침해 대응, 접근 제한과 보존 범위, 양 당사자에게 공유할 개인정보는 별도 검토합니다.

## 운영 검토 체크

사건은 수신 → 형식·관할 확인 → 최소 범위 조치 여부 결정 → 당사자 안내 → 이의 검토 → 종결/재검토 흐름으로 관리하는 방안을 검토합니다. 원본 공개·영구 삭제·법원 제출 같은 조치는 담당자가 근거와 범위를 확인한 뒤 수행합니다. 자체 DB의 삭제 차단 트리거가 법적 보존 의무를 자동으로 성립시키는 것은 아닙니다.
