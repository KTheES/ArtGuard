# 마켓 수집·이미지 저장 운영 정책 초안

**내부 검토용. 실제 계정 계약·데이터 재이용 권한과 배포 설정 확인 전 외부 수집 승인을 뜻하지 않습니다.**

현재 AliExpress 코드는 제휴 상품 API 준비이며 전체 마켓 전수 검색이 아닙니다. [구현·계정 미검증 범위](../STEP12_ALIEXPRESS.md)를 기준으로 API 권한, 허용 호출량, 검색 목적, 상품·이미지 저장, 재표시, 증거 보존, 탈퇴 후 삭제, 재위탁·국외 처리를 계약 문서와 대조합니다. 공개 API 문서나 robots.txt만으로 저작권·개인정보·약관상 재이용 권한이 확보됐다고 판단하지 않습니다.

마켓별 운영 기록에는 공급자/계정, 적용 계약 버전과 확인일, 허용 데이터·목적·주기, 이미지 원본 호스트, 저장·표시 기간, 제한·철회·연락처, 검토 담당자를 남깁니다. 이 표는 현재 미작성 상태입니다. 접근 차단·로그인·CAPTCHA·속도 제한을 우회하는 기능은 도입하지 않는 운영 방침으로 검토합니다. 외부 원본 이미지 다운로드의 기술적 접근 통제와 이용권한 검토는 별개입니다.

작품은 정규화 이미지·썸네일과 특징값으로 처리하고, 선택적 PSD/Procreate 첨부는 원본 바이트로 별도 보관합니다. 사용자 업로드에는 제3자 개인정보나 제작 파일 내부 정보가 포함될 수 있습니다. 탐지 증거의 SVG는 저장 메타데이터로 만든 요약이며 원본 마켓 화면 캡처라고 표시하지 않습니다.

접근은 작품 소유자·허용된 관리자·짧은 서명 URL 등 구현 경로에 따라 제한하되, 실제 버킷 공개 설정·키 접근·로그·백업·키 회전은 운영 환경에서 별도 검증합니다. 상품 사진의 재배포나 다운로드를 무제한 허용하는 정책으로 확대하지 않습니다.

보유기간은 [데이터 목록](DATA_INVENTORY_RETENTION.md)과 일치시켜 확정합니다. 고아 S3 객체·버전·미완료 업로드·임시 파일·파생 이미지까지 포함합니다. 증거 불변성과 파기 요구가 충돌하면 승인된 별도 파기 절차와 기록을 설계하며, 일반 API에서 트리거를 끄거나 무차별 삭제하지 않습니다. 운영 정책 확정 전 파기 스크립트를 실행하지 않았습니다.
